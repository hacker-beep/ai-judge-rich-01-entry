A $100, 30-day plan to sell finished quote websites to plumbers whose Facebook advertising leads only to Facebook pages. Live previews precede outreach, wallet payment is agreed before custom edits, and monthly care provides a second revenue line. The plan specifies a daily schedule, budget, discounted sales funnel, cash floor and switching rules. Revenue figures are planning assumptions, not measured results. The Node 22 entry uses only the standard library and deterministically writes one fixed UTF-8 plan to `entry.txt`, without network access, clocks or randomness.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Without `MAKEFUN_OUTPUT_DIR`, the output directory is `/output`. The program creates the directory if necessary.
